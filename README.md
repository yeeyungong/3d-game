# 暗蚀协议 · 3D 本地试玩原型

8 人、无怪物的社交推理游戏规则验证工具。原始内鬼最多转换两名好人；第一次开局可用，第二次通过三项秘密任务解锁。任务获取共享能量，100 能量可开会投票。

## 启动

需要 Node.js 22 或更新版本。3D 场景使用本地 Three.js；首次获取项目后运行 `npm ci` 安装锁定依赖，日常启动无需联网。

```powershell
npm start
```

浏览器打开 http://127.0.0.1:4173 。服务仅监听本机。关闭终端或按 Ctrl+C 停止。

```powershell
npm test
```

## 如何试玩

1. 点击“进入研究站”，默认控制原始内鬼林舟。
2. 点击 3D 场景后使用 WASD/方向键移动，Shift 加速；拖动旋转镜头、滚轮缩放，也可点击地面行走。手机端可按住屏幕方向键。前往区域按钮让人物实际走向区域中心，会绕开已配置的设备障碍。在右侧完成任务后，资源自动进入公共池。
3. 打开“模拟控制台”，可暂停、选择 1/4/10 倍速度、推进 15 秒或切换八名玩家。暂停只冻结时钟，仍允许操作，方便布置测试场景。
4. 开局保护 15 秒后，在同房间对好人引导转换 5 秒；移动或受伤会打断，不消耗次数。
5. 按供电区→实验室→通讯区完成秘密任务，解锁第二次转换。两次成功转换间隔至少 45 秒。
6. 攒满 100 能量，返回中央大厅启动会议。讨论 60 秒，投票 20 秒。在会议面板切换模拟玩家分别投票；需要超过全部存活玩家一半的票数才能淘汰。
7. 所有内鬼死亡则好人胜利，否则存活好人不超过两人则内鬼胜利。结束后可查看身份与时间线，并重新开始。

内鬼近战一次淘汰目标，击杀冷却 20 秒；好人不能攻击。攻击、转换在会议及安全保护期间无效。终端冷却后可再次提供资源，保证后期继续开会的途径。

## 原型边界

- 已提供真正的实时 3D 场景、低多边形人形角色、行走动画、跟随镜头和基础设备碰撞；这是本地原型，尚未联网。
- 七名其他玩家没有 AI，由设计者切换操作；不生成伪装为真人的对话。
- 走入区域会切换任务。当前仍以同区域作为交互范围，尚未使用精确近距离和遮挡判定；不代表最终战斗距离。
- 身份界面按当前玩家过滤，但完整状态存在浏览器内存中，不具备联网所需的服务器秘密隔离。
- 本阶段仅包含四个单人资源点；运输、双人任务、装备、破坏、环境痕迹、语音和文字聊天未实现。
- 隐藏浏览器标签时模拟时钟暂停。页面不保存进度，刷新会重新开局。
- 本地演练不能证明真实多人局的平衡性，尤其需要后续验证 3 好人对 3 内鬼时的投票僵局。
- 键盘移动需先点击场景使其获得焦点。模拟暂停只冻结规则时钟，仍允许走动与操作；会议时禁止走动。

## 手动验收

- 转换第一人后切换至目标，验证目标身份和私人提示改变。
- 分别完成三项秘密任务；等待冷却后转换第二人，再次尝试第三人应不可用。
- 任务做到 100 能量，开会投票；投票不足过半时不得淘汰，能量仍消耗。
- 投出原始内鬼且仍有被转换者，游戏应继续；消灭最后内鬼后好人胜利。
- 连续重开三次，每次应为八人存活、0 能量、0 次转换，只有一个时钟。
- 在桌面与手机宽度下检查按钮、地图、会议和模拟控制台可操作。

### 五区场景
供电区使用金黄发电设备；实验室使用冷蓝实验台和样本罐；仓储区使用橙色货箱；通讯区使用紫色服务器；中央大厅使用蓝色紧急会议桌。外围维护通道照度较低，设备具有已有的行走碰撞。区域导航会调整镜头朝向，拖动仍可自由旋转。

暗角仅影响画面明暗和几何遮挡，不提供隐身状态；攻击目前仍以同区域为范围。

地图现已扩建：长宽为原来的 1.7 倍，面积约 2.9 倍；新增带出入口的隔墙与碰撞，自动导航会绕行。人物尺寸、行走速度不变，可按 Shift 加速。攻击范围仍沿用同区域规则。

### 当前试玩操作（更新）
- 游戏直接铺满窗口，不再显示区域跳转按钮或逐个玩家的操作列表。
- WASD/方向键移动，Shift 加速；J 转换、K 攻击。红圈标记 3.5 单位内、无遮挡且同区域的最近玩家。
- 到达房间后点击任务按钮打开互动面板：供电接线、实验室按编号扫描、仓储货单开关、通讯频段滑块。秘密任务使用对应房间的操作面板。
- 实际试玩必须完成关卡才有奖励；退出（X / Esc）会中断。规则测试保留非交互计时模式，不代表当前试玩行为。
- 30 项测试通过；浏览器验证了 J/K、接线错误提示、正确接线获得 15 能量、关闭不领奖，以及 390px 宽度无横向溢出。

### 多人邀请版
入口现在默认提供创建房间、输入房间码和分享邀请链接。正式房间须 4–8 人全部准备后由房主开始。已连接真实多人服务器，支持移动、任务奖励、攻击、身份转换、会议与投票同步，并保留单人练习。

部署请优先阅读 [DEPLOYMENT.md](./DEPLOYMENT.md)：Vercel 部署网页，另外部署 Node WebSocket 服务（提供 render.yaml）。只把静态网页上传 Vercel 不会产生联机服务器。服务器当前为单实例内存房间，重启后需重新创建房间。
